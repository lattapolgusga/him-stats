# HIM Stats — ระบบเก็บสถิติคริสตจักร H.I.M. Thailand

เว็บแอป (LINE LIFF) + Google Sheet + Apps Script + LINE OA "งานพันธกิจ H.I.M."

> repo นี้มีแค่โค้ด ไม่มีข้อมูลคริสตจักร ข้อมูลทั้งหมดอยู่ใน Google Sheet กลาง

## การใช้งาน
- **เว็บแอป:** https://lattapolgusga.github.io/him-stats/ (เข้าด้วย username / password)
- **แอดมิน:** สร้างบัญชีในเมนู "ผู้ใช้" ระบบจะออกรหัสผ่านชั่วคราวให้ แล้วส่งให้ผู้นำแบบส่วนตัว
- **LINE OA (เลขา):** ผู้ใช้ไปที่เมนู "บัญชีของฉัน" → ขอรหัสเชื่อม แล้วพิมพ์ `เชื่อม 123456` ในแชท OA จากนั้นถามได้ เช่น "สรุปภาพรวม", "ยังไม่ส่ง", "ยอดลด", "สรุปภาค อีสาน 4"
- รหัสผ่านเก็บเป็น hash (SHA-256 + salt) ในแท็บ "ผู้ใช้" · session หมดอายุ 6 ชม. · ล็อกหลังใส่รหัสผิด 5 ครั้ง

## อัปเดตระบบหลังบ้านจาก Terminal
